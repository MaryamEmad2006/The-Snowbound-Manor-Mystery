# The Winterbell Estate Murder – Detective Game

## Project Description
The Winterbell Estate Murder is a C++ detective game where the player investigates the mysterious murder of Duke Winterbell by examining evidence, reviewing suspects, checking alibis, and analyzing witness statements to identify the real killer.

## Project Objectives
- Develop a simple detective investigation game using C++.
- Apply Object-Oriented Programming concepts.
- Practice working with classes, objects, and inheritance.
- Create an interactive console-based interface.

## OOP Concepts Applied

- **Classes and Objects:** Person, Evidence, Suspect, Witness, and DetectiveGame.
- **Encapsulation:** Using private data members and public getter functions.
- **Constructors and Destructors:** Initializing and managing class objects.
- **Inheritance:** Suspect and Witness inherit from Person.
- **Polymorphism:** Using virtual functions and function overriding.
- **Function Overloading:** Using two showEvidence() functions with different parameters.
- **Access Modifiers:** Using private, public, and protected.

## Project Files

- `main.cpp` – Contains the main function and game menu.
- `Investigation.h` – Contains class declarations.
- `Investigation.cpp` – Contains class implementations.



## How to Play

1. Choose an option from the main menu.
2. Examine the available evidence.
3. Review the suspects and their alibis.
4. Read the witness statements and detective hints.
5. Make your final accusation and try to identify the real murderer.

## Technologies Used
